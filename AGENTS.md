# CapCut work

For CapCut editing tasks in this workspace, read `CAPCUT_MEMORY.md` first and use the installed `ipnimma-capcut` skill when available. The user's latest explicit instructions override saved defaults. Do not treat clip-specific facts as reusable preferences.

For learning or recalling editing preferences, use `capcut-editing-memory` (workspace source: `skills/capcut-editing-memory/SKILL.md`). Read backend files only, and retain source-backed BGM, SFX, transition, and text X/Y observations separately from confirmed defaults.

Update the memory when the user explicitly asks to remember a preference or clearly establishes a reusable editing default. Keep uncertain choices and one-off instructions out of confirmed defaults.
